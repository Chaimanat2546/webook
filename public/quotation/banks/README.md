# Generic bank icons

These local SVG assets are generic bank-building icons for the built-in Thai
bank catalogue. They are not official bank logos or trademarks.

Every icon uses the same `48 x 48` duotone seal and differs only by its bank
colour. Keep the existing filenames because saved quotation snapshots refer to
these public paths.

Asset rules:

- vector paths and basic shapes only;
- no embedded raster images, Base64 payloads, external URLs, gradients, or filters;
- `generic-bank.svg` is the neutral fallback for `OTHER`.
